## 🎯 Sobre o Projeto

**CRM Landing Page** é uma interface web elegante e totalmente responsiva projetada para apresentar uma plataforma de **Customer Relationship Management (CRM)**. Construída com foco em design moderno, desempenho e experiência do usuário, o objetivo é converter visitantes em leads qualificados.

> Perfeita para empresas e startups que desejam apresentar seu produto de CRM com uma presença digital profissional e atraente.

---

## ✨ Funcionalidades

- 🎨 **Design Moderno** — Interface limpa com uma paleta de cores cuidadosamente elaborada
- 📱 **Totalmente Responsiva** — Otimizada para desktop, tablet e celular
- ⚡ **Alto Desempenho** — Código enxuto para tempos de carregamento rápidos
- 🎭 **Animações Suaves** — Transições elegantes e efeitos visuais
- 📊 **Seção de Funcionalidades** — Destaca as principais capacidades do CRM
- 💬 **Depoimentos** — Prova social para aumentar as conversões
- 💰 **Tabela de Preços** — Planos e preços apresentados com clareza
- 📬 **Formulário de Contato / CTA** — Seção estratégica de call-to-action
- 🌐 **Amigável para SEO** — Estrutura HTML semântica para melhor indexação

## 🚀 Começando

### Pré-requisitos

Nenhuma dependência externa necessária — apenas um navegador moderno! ✅

### Instalação

```bash
# 1. Clone o repositório
git clone https://github.com/ChristopherDond/CRM_LandingPage.git

# 2. Navegue até a pasta do projeto
cd CRM_LandingPage

# 3. Abra o arquivo principal no seu navegador
# No Linux/macOS:
open index.html

# No Windows:
start index.html
```

> 💡 **Dica:** Use a extensão [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) no VS Code para uma melhor experiência de desenvolvimento com recarregamento automático.
